Key Features: Accessibility Awareness Design · Flex Sensor Input Mapping · Accelerometer Joystick Control · Iterative Hardware Prototyping · Live Game Validation

Overview: A wearable glove-based game controller built to simulate the accessibility challenges faced by disabled gamers. By deliberately designing an unconventional and uncomfortable input device, the project builds empathy among players and developers for the importance of inclusive design in gaming.

Link: Vertically Intergrated Project

Contributions:

    Art & Design

  • Designed and iterated on multiple controller layouts, narrowing from a two-handed full-button scheme down to a focused 3 flex sensor, 2 button, and accelerometer configuration.
  • Physically constructed and reworked the glove, securing breadboards with Velcro and hot glue, and stabilizing flex sensors with sewn wire supports and finger sleeve covers.
  • Refined sensor consistency by adding sleeve covers that held flex sensors in place, improving input reliability

    • Development

  • Integrated flex sensors onto the center three fingers, mapping bend input to ABXY and Start buttons.
  • Mounted an accelerometer/tilt sensor to the top of the hand for left joystick control.
  • Tested and validated the controller in a live game environment, successfully completing a level in Duck Game.

Impact:

  • Modular rig architecture enables combinatorial customization without additional modeling work per variant.
  • Reduced cross-discipline handoff friction by handling 3D production and systems integration.
  • Navigated a full engine migration mid-project, delivering a working holographic build under time constraint.
